# Local Field Videos Folder (`videos/`)

This folder is reserved for offline-friendly MP4 field demonstrations (such as local Narowal farmer clips on Happy Seeder sowing, AWD pipe installation, and 5-layer compost making).

- Keep video clips short (30–90 seconds) and compressed (`480p` MP4) so they play reliably on low-cost Android phones and load smoothly on GitHub Pages.
- The **Learning Videos** section in `app.js` already provides interactive animated step-by-step walkthroughs that work immediately with zero network dependency, and can also link directly to any `.mp4` files placed here.
